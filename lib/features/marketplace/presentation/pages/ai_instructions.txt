FamHub AI Instructions Summary
Core Identity
Project: Famhub - AgriTech Flutter app for Farmers & Agricultural Buyers
Stack: Flutter (Dart), Supabase (PostgreSQL), Riverpod v2.x, GoRouter
Key Focus: Rural accessibility, low-data usage, offline-first, security via RLS

🎯 Strategic Principles
Goal	Implementation
Performance	Low-data usage for rural areas
Security	Supabase RLS mandatory (users see only their data)
Offline First	CacheService with background sync
Architecture	Modular, multi-platform, self-registering
📁 Project Structure

lib/├── main.dart (minimal entry point)├── shared/layout/ (MainShell, DashboardShell)├── core/ (Providers, Services, Database, Theme)├── features/module_name/ (self-contained modules)└── system/ (Module, Dashboard, Role registries)
🚫 Critical Rules
NO-SCAFFOLD RULE: Modules MUST NOT contain Scaffold, AppBar, or BottomNavigationBar — these belong exclusively in MainShell.

Responsive Root Structure:
